正文

C++17 语言特性

类模板的模板参数自动推导

现在类的构造函数能用来推导类模板参数了，就像推导函数模板那样。

C++ 
template <typename T = float>struct MyContainer {    T val;    MyContainer() : val{} {}    MyContainer(T val) : val{val} {}    // ...};MyContainer c1 {1}; // 推导为 MyContainer<int>MyContainer c2; // 推导为 MyContainer<float>

使用auto声明非类型模板参数

在涉及到所允许类型的非类型模板参数列表 [*] 中，遵循 auto 的推导规则，可以从其参数类型中推导出模板参数。

C++ 
template <auto... seq>struct my_integer_sequence {    // 相关实现 ...};// 显式传递“int”类型作为模板参数。auto seq = std::integer_sequence<int, 0, 1, 2>();// 类型被推导为“int”。auto seq2 = my_integer_sequence<0, 1, 2>();

※ 例如，你不能使用 double 类型的模板参数，这也会使得 auto 的推导无效。

折叠表达式

折叠表达式会在二进制运算符上执行一个模板参数包的折叠。

  • 形式为 (...op e) 或 (e op...) 的表达式，其中 op 是折叠运算符，e 是未展开的参数包，这种表达式被称为 一元折叠。
  • 形式为 (e1 op...op e2) 的表达式，其中 op 是折叠运算符，这种表达式被称为 二元折叠。e1 或 e2 其中一个是未展开参数包，但不能两者都是。
C++ 
template <typename... Args>bool logicalAnd(Args... args) {    // 二元折叠。    return (true && ... && args);}bool b = true;bool& b2 = b;logicalAnd(b, b2, true); // == true
C++ 
template <typename... Args>auto sum(Args... args) {    // 一元折叠。    return (... + args);}sum(1.0, 2.0f, 3); // == 6.0

auto推导braced-init-list的新规则

使用统一的初始化语法时，对 auto 推导规则进行改变。以前， auto x{3}; 会推导为 std::initializer_list<int> ，现在会推导为 int 。

C++ 
auto x1 {1, 2, 3}; // 错误：不是单一元素auto x2 = {1, 2, 3}; // x2 的类型为 std::initializer_list<int>auto x3 {3}; // x3 的类型为 intauto x4 {3.0}; // x4 的类型为 double

constexpr lambda

编译期 lambda 表达式使用 constexpr 。

C++ 
auto identity = [](int n) constexpr { return n; };static_assert(identity(123) == 123);
C++ 
constexpr auto add = [](int x, int y) {  auto L = [=] { return x; };  auto R = [=] { return y; };  return [=] { return L() + R(); };};static_assert(add(1, 2)() == 3);
C++ 
constexpr int addOne(int n) {  return [n] { return n + 1; }();}static_assert(addOne(1) == 2);

lambda表达式按值捕获 this

以前在 lambda 表达式中捕获 this 指针只能引用捕获。一个会造成问题的例子：如果在一个异步回调里要捕获对象，这个回调里要求对象可用，但是可能已经超过该对象的生存周期。现在C++17里使用 *this 会对当前对象做一个拷贝，而使用 this (C++11) 将继续使用引用捕获。

C++ 
struct MyObj {  int value {123};  auto getValueCopy() {    return [*this] { return value; };  }  auto getValueRef() {    return [this] { return value; };  }};MyObj mo;auto valueCopy = mo.getValueCopy();auto valueRef = mo.getValueRef();mo.value = 321;valueCopy(); // 123valueRef(); // 321

内联变量

内联说明符 inline 既可以用于变量，又可以用于函数。定义为内联变量和内联函数具有相同的语义。

C++ 
// 使用compiler explorer的反汇编示例。struct S { int x; };inline S x1 = S{321}; // mov esi, dword ptr [x1]                      // x1: .long 321S x2 = S{123};        // mov eax, dword ptr [.L_ZZ4mainE2x2]                      // mov dword ptr [rbp - 8], eax                      // .L_ZZ4mainE2x2: .long 123

还可以用其来声明和定义一个静态成员变量，这样就不需要在源文件中初始化了。

C++ 
struct S {  S() : id{count++} {}  ~S() { count--; }  int id;  static inline int count{0}; // 在类里定义及初始化 count 变量为 0。};

嵌套命名空间

使用命名空间解析运算符来创建嵌套命名空间。

C++ 
namespace A {  namespace B {    namespace C {      int i;    }  }}

上面的代码也可以这么写：

C++ 
namespace A::B::C {  int i;}

结构化绑定

一个去结构化初始化的提议，允许写 auto [x, y, z] = expr; 这种表达式，其中 expr 是一个元组形式的对象，其中的元素会被绑定到变量 x, y, z（这个表达式中声明的）。元组形式包括 std::tuple、std::pair、std::array 以及聚合结构。

C++ 
using Coordinate = std::pair<int, int>;Coordinate origin() {  return Coordinate{0, 0};}const auto [ x, y ] = origin();x; // == 0y; // == 0
C++ 
std::unordered_map<std::string, int> mapping {  {"a", 1},  {"b", 2},  {"c", 3}};// 使用引用解构for (const auto& [key, value] : mapping) {  // 使用 key 和 value 的相关代码逻辑}

带有初始值的选择语句

新版本的 if 和 switch 语句简化了常见的代码结构，并帮助用户使代码更紧凑。

C++ 
{  std::lock_guard<std::mutex> lk(mx);  if (v.empty()) v.push_back(val);}// 现在：if (std::lock_guard<std::mutex> lk(mx); v.empty()) {  v.push_back(val);}
C++ 
Foo gadget(args);switch (auto s = gadget.status()) {  case OK: gadget.zip(); break;  case Bad: throw BadFoo(s.message());}// 现在：switch (Foo gadget(args); auto s = gadget.status()) {  case OK: gadget.zip(); break;  case Bad: throw BadFoo(s.message());}

constexpr if

编写根据编译时条件实例化的代码。

C++ 
template <typename T>constexpr bool isIntegral() {  if constexpr (std::is_integral<T>::value) {    return true;  } else {    return false;  }}static_assert(isIntegral<int>() == true);static_assert(isIntegral<char>() == true);static_assert(isIntegral<double>() == false);struct S {};static_assert(isIntegral<S>() == false);

UTF-8字符字面量

以 u8 开头的 char 类型字面量。一个 UTF-8 字面量的值与 ISO 10646 所对应的值相同。

C++ 
char x = u8'x';

枚举用列表直接初始化

现在枚举能用大括号表达式初始化了。

C++ 
enum byte : unsigned char {};byte b {0}; // 正确byte c {-1}; // 错误byte d = byte{1}; // 正确byte e = byte{256}; // 错误

[[fallthrough]], [[nodiscard]], [[maybe_unused]] attributes

C++17 引入了三种新的 attributes：[[fallthrough]]，[[nodiscard]] 以及 [[maybe_unused]]。

  • [[fallthrough]] 告诉编译器在 switch 语句中不 break 直接往后执行是预期行为。这个 attribute 必须在 switch 语句中使用，并且必须在下一个 case/default 标签前面。
C++ 
switch (n) {  case 1:     // ...    [[fallthrough]];  case 2:    // ...    break;  case 3:    // ...    [[fallthrough]];  default:    // ...}
  • [[nodiscard]] 当函数或类含有此 attribute，并且返回值被丢弃时，会触发警告。
C++ 
[[nodiscard]] bool do_something() {  return is_success; // 成功返回 true，失败返回 false。}do_something(); // 警告: 忽略 'bool do_something()' 函数的返回值,                // 声明使用了 attribute 'nodiscard'
  • [[maybe_unused]] 告诉编译器某个变量或参数未使用是预期行为。
C++ 
void my_callback(std::string msg, [[maybe_unused]] bool error) {  // 不要管“msg”是不是错误消息，就硬打log。  log(msg);}

__has_include

__has_include(operand) 表达式会用在 #if 和 #elif 表达式中检测头文件或源文件 operand 是否可以被包含。

这样做的一个用例是：使用两个以相同方式工作的库，如果系统找不到首选库，就使用另一个备份库。

C++ 
#ifdef __has_include#  if __has_include(<optional>)#    include <optional>#    define have_optional 1#  elif __has_include(<experimental/optional>)#    include <experimental/optional>#    define have_optional 1#    define experimental_optional#  else#    define have_optional 0#  endif#endif

它还可以用在在不同平台上以不同名称或位置存在的头文件，不知道程序会在哪个平台上运行。OpenGL 就是个很好的例子，在 macOS 上路径为 OpenGL/ ，而其他平台上是 GL/。

C++ 
#ifdef __has_include#  if __has_include(<OpenGL/gl.h>)#    include <OpenGL/gl.h>#    include <OpenGL/glu.h>#  elif __has_include(<GL/gl.h>)#    include <GL/gl.h>#    include <GL/glu.h>#  else#    error No suitable OpenGL headers found.# endif#endif

类模板参数推导

类模板参数推导（Class template argument deduction，CTAD）允许编译器通过构造函数的参数推导模板参数。

C++ 
std::vector v{ 1, 2, 3 }; // 推导为 std::vector<int>std::mutex mtx;auto lck = std::lock_guard{ mtx }; // 推导为 std::lock_guard<std::mutex>auto p = new std::pair{ 1.0, 2.0 }; // 推导为 std::pair<double, double>*

对于用户自定义类型，可以使用 推断指引（deduction guides），以在合适的情况下指导编译器如何推断模板参数。

C++ 
template <typename T>struct container {  container(T t) {}  template <typename Iter>  container(Iter beg, Iter end);};// 推断指引template <template Iter>container(Iter b, Iter e) -> container<typename std::iterator_traits<Iter>::value_type>;container a{ 7 }; // 正确: 推导为 container<int>std::vector<double> v{ 1.0, 2.0, 3.0 };auto b = container{ v.begin(), v.end() }; // 正确: 推断为 container<double>container c{ 5, 6 }; // 错误: std::iterator_traits<int>::value_type 不是个类型。

C++17 库特性

std::variant

类模板 std::variant 是一个类型安全的 union。一个 std::variant 实例在任何时候都持有其可替代类型之一的值（也有可能是无值的）。

C++ 
std::variant<int, double> v{ 12 };std::get<int>(v); // == 12std::get<0>(v); // == 12v = 12.0;std::get<double>(v); // == 12.0std::get<1>(v); // == 12.0

std::optional

类模板 std::optional 管理一个可选的包含值，即一个可能存在也可能不存在的值。一个常见的用例是作为一个可能失败的函数的返回值。

C++ 
std::optional<std::string> create(bool b) {  if (b) {    return "Godzilla";  } else {    return {};  }}create(false).value_or("empty"); // == "empty"create(true).value(); // == "Godzilla"// 返回 optional 的工厂函数可以作为 while 和 if 的条件。if (auto str = create(true)) {  // ...}

std::any

一个任意类型单一值的类型安全容器。

C++ 
std::any x {5};x.has_value() // == truestd::any_cast<int>(x) // == 5std::any_cast<int&>(x) = 10;std::any_cast<int>(x) // == 10

std::string_view

对于字符串的非所有者引用。适合用于在字符串之上提供抽象（例如解析字符串）。

C++ 
// 普通字符串。std::string_view cppstr {"foo"};// 宽字符串。std::wstring_view wcstr_v {L"baz"};// 字符数组。char array[3] = {'b', 'a', 'r'};std::string_view array_v(array, std::size(array));
C++ 
std::string str {"   trim me"};std::string_view v {str};v.remove_prefix(std::min(v.find_first_not_of(" "), v.size()));str; //  == "   trim me"v; // == "trim me"

std::invoke

调用一个带参的可调用对象。可调用对象的例子有 std::function 和 lambda 表达式。这个对象可以像通常的函数一样调用。

C++ 
template <typename Callable>class Proxy {  Callable c_;public:  Proxy(Callable c) : c_{ std::move(c) } {}  template <typename... Args>  decltype(auto) operator()(Args&&... args) {    // ...    return std::invoke(c_, std::forward<Args>(args)...);  }};const auto add = [](int x, int y) { return x + y; };Proxy p{ add };p(1, 2); // == 3

std::apply

调用一个元组参数的可调用对象。

C++ 
auto add = [](int x, int y) {  return x + y;};std::apply(add, std::make_tuple(1, 2)); // == 3

std::filesystem

新的 std::filesystem 库提供了一种操作文件、文件夹以及路径的标准方式。

这里的例子，如果有足够的空间，一个大文件会被拷贝到临时路径：

C++ 
const auto bigFilePath {"bigFileToCopy"};if (std::filesystem::exists(bigFilePath)) {  const auto bigFileSize {std::filesystem::file_size(bigFilePath)};  std::filesystem::path tmpPath {"/tmp"};  if (std::filesystem::space(tmpPath).available > bigFileSize) {    std::filesystem::create_directory(tmpPath.append("example"));    std::filesystem::copy_file(bigFilePath, tmpPath.append("newFile"));  }}

std::byte

新的 std::byte 提供了一种表示字节数据的标准方法。使用 std::byte 相比于 char 或 unsigned char 的好处是，这不是一个字符类型，也不是一个算数类型。它只能使用位运算。

C++ 
std::byte a {0};std::byte b {0xFF};int i = std::to_integer<int>(b); // 0xFFstd::byte c = a & b;int j = std::to_integer<int>(c); // 0

注意 std::byte 只是一个简单的枚举，感谢 枚举用列表直接初始化 让大括号初始化这个枚举成为可能。

剪接map和set

移动节点和合并容器，不再需要昂贵的拷贝、移动或堆的分配/释放开销。

把元素从一个 map 移动到另一个：

C++ 
std::map<int, string> src {{1, "one"}, {2, "two"}, {3, "buckle my shoe"}};std::map<int, string> dst {{3, "three"}};dst.insert(src.extract(src.find(1))); // 廉价地从 src 中移除 { 1, "one" } 并将其移动到 dst。dst.insert(src.extract(2)); // 廉价地从 src 中移除 { 2, "two" } 并将其移动到 dst。// dst == { { 1, "one" }, { 2, "two" }, { 3, "three" } };

插入整个 set：

C++ 
std::set<int> src {1, 3, 5};std::set<int> dst {2, 4, 5};dst.merge(src);// src == { 5 }// dst == { 1, 2, 3, 4, 5 }

插入比容器生命周期长的元素：

C++ 
auto elementFactory() {  std::set<...> s;  s.emplace(...);  return s.extract(s.begin());}s2.insert(elementFactory());

改变 map 中元素的 key：

C++ 
std::map<int, string> m {{1, "one"}, {2, "two"}, {3, "three"}};auto e = m.extract(2);e.key() = 4;m.insert(std::move(e));// m == { { 1, "one" }, { 3, "three" }, { 4, "two" } }

并行算法

许多STL算法，例如 copy、find 和 sort 方法，开始支持并行处理策略：seq、par 和 par_unseq，意思分别为“顺序地”、“并行地”以及“并行乱序地”：

C++ 
std::vector<int> longVector;// 使用并行处理策略查找元素。auto result1 = std::find(std::execution::par, std::begin(longVector), std::end(longVector), 2);// 使用顺序处理策略排序元素。auto result2 = std::sort(std::execution::seq, std::begin(longVector), std::end(longVector));

std::sample

对 n 个元素进行采样（不替换），每个元素都有相等的机会被选中。

C++ 
const std::string ALLOWED_CHARS = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789";std::string guid;// 从 ALLOWED_CHARS 里采样 5 个字符。std::sample(ALLOWED_CHARS.begin(), ALLOWED_CHARS.end(), std::back_inserter(guid),  5, std::mt19937{ std::random_device{}() });std::cout << guid; // 可能结果：G1fW2

std::clamp

限制给定数值的上下限。

C++ 
std::clamp(42, -1, 1); // == 1std::clamp(-42, -1, 1); // == -1std::clamp(0, -1, 1); // == 0// std::clamp 也可以接受自定义比较函数：std::clamp(0, -1, 1, std::less<>{}); // == 0

std::reduce

折叠给定范围的元素。概念上类似 std::accumulate，但是 std::reduce 会并行执行折叠。由于折叠是并行完成的，如果你制定二元运算符，就要求它是关联的和可交换的。给定的二元运算符不能在给定范围内，改变任何元素或使迭代器无效。

默认的二元运算符是 std::plus，初始值是 0。

C++ 
const std::array<int, 3> a{ 1, 2, 3 };std::reduce(std::cbegin(a), std::cend(a)); // == 6// 使用自定义二元运算：std::reduce(std::cbegin(a), std::cend(a), 1, std::multiplies<>{}); // == 6

另外，你还可以指定转换器：

C++ 
std::transform_reduce(std::cbegin(a), std::cend(a), 0, std::plus<>{}, times_ten); // == 60const std::array<int, 3> b{ 1, 2, 3 };const auto product_times_ten = [](const auto a, const auto b) { return a * b * 10; };std::transform_reduce(std::cbegin(a), std::cend(a), std::cbegin(b), 0, std::plus<>{}, product_times_ten); // == 140

前缀和算法

支持前缀和算法：

C++ 
const std::array<int, 3> a{ 1, 2, 3 };std::inclusive_scan(std::cbegin(a), std::cend(a),    std::ostream_iterator<int>{ std::cout, " " }, std::plus<>{}); // 1 3 6std::exclusive_scan(std::cbegin(a), std::cend(a),    std::ostream_iterator<int>{ std::cout, " " }, 0, std::plus<>{}); // 0 1 3const auto times_ten = [](const auto n) { return n * 10; };std::transform_inclusive_scan(std::cbegin(a), std::cend(a),    std::ostream_iterator<int>{ std::cout, " " }, std::plus<>{}, times_ten); // 10 30 60std::transform_exclusive_scan(std::cbegin(a), std::cend(a),    std::ostream_iterator<int>{ std::cout, " " }, 0, std::plus<>{}, times_ten); // 0 10 30

GCD和LCM

最大公因数（greatest common divisor，GCD）和最小公倍数（least common multiple，LCM）。

C++ 
const int p = 9;const int q = 3;std::gcd(p, q); // == 3std::lcm(p, q); // == 9

std::not_fn

给定函数的相反结果。

C++ 
const std::ostream_iterator<int> ostream_it{ std::cout, " " };const auto is_even = [](const auto n) { return n % 2 == 0; };std::vector<int> v{ 0, 1, 2, 3, 4 };// 打印所有偶数。std::copy_if(std::cbegin(v), std::cend(v), ostream_it, is_even); // 0 2 4// 打印所有奇数（非偶数）。std::copy_if(std::cbegin(v), std::cend(v), ostream_it, std::not_fn(is_even)); // 1 3

字符串和数字互转

将整数或浮点数转换为字符串，反之亦然。转换不抛出异常，不分配内存，并且比C语言标准库更安全。

用户有责任为 std::to_chars 分配足够多的空间，否则函数会失败并返回一个错误码。

函数允许你指定进制（默认十进制），或者制定浮点输入类型。

  • std::to_chars 返回一个（非const）字符指针和一个错误码对象，该指针位于函数在给定缓冲区内写入的字符串的末尾。
  • std::from_chars 返回一个常字符指针和一个错误码对象，该指针指向传入函数的指针末尾。

这两个函数在成功时都返回默认初始化的错误码对象。

把数字 123 转换到 std::string：

C++ 
const int n = 123;// 可以使用任何容器：string，array 等等。std::string str;str.resize(3); // 对数字 n 的转换结果提供足够的存储空间。const auto [ ptr, ec ] = std::to_chars(str.data(), str.data() + str.size(), n);if (ec == std::errc{}) { std::cout << str << std::endl; } // 123else { /* 转换失败的处理 */ }

把类型为 std::string 的 “123” 转换为数字：

C++ 
const std::string str{ "123" };int n;const auto [ ptr, ec ] = std::from_chars(str.data(), str.data() + str.size(), n);if (ec == std::errc{}) { std::cout << n << std::endl; } // 123else { /* 转换失败的处理 */ }

chrono 中 durations 和 timepoints 的取整函数

对 std::chrono::duration 和 std::chrono::time_point 提供绝对值、四舍五入、向上取整以及向下取整的辅助函数。

C++ 
using seconds = std::chrono::seconds;std::chrono::milliseconds d{ 5500 };std::chrono::abs(d); // == 5sstd::chrono::round<seconds>(d); // == 6sstd::chrono::ceil<seconds>(d); // == 6sstd::chrono::floor<seconds>(d); // == 5s
