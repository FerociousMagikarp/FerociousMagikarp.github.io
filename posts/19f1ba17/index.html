C++20语言特性

协程

注意：这些例子只是基础地解释一下如何使用协程，如果想要代码编过还需要做很多工作。这些例子并不意味着能完全覆盖 C++20 协程。目前标准库还没提供 generator 和 task 类，我使用了 cppcoro 库来编译这些例子。

协程（coroutine）是一种特殊的函数，可以暂停和恢复运行。要定义协程，函数体中必须有 co_return、co_await 或 co_yield 关键字。C++20 的协程是无栈协程，除非编译器进行优化，否则其状态将在堆上分配。

协程的一个例子是 生成器 函数，每次调用都会产生一个值：

C++ 
generator<int> range(int start, int end) {  while (start < end) {    co_yield start;    start++;  }  // 这个函数的末尾有个隐式的 co_return：  // co_return;}for (int n : range(0, 10)) {  std::cout << n << std::endl;}

上述 range 生成器函数从 start 到 end（不包含）生成值，每个迭代步骤产生的当前值存储在 start 中。生成器在每次 range 函数调用时都保持其状态（这个用例中，调用就是 for 循环中的每次迭代）。co_yield 接受给定表达式，产生其值，并在此节点挂起协程。协程恢复后，将在 co_yield 节点之后继续执行。

协程的另一个例子是 任务，在任务等待时执行异步计算。

C++ 
task<void> echo(socket s) {  for (;;) {    auto data = co_await s.async_read();    co_await async_write(s, data);  }  // 这个函数的末尾有个隐式的 co_return：  // co_return;}

在这个例子中引入了 co_await 关键字。这个关键字接受一个表达式，如果正在等待的东西没准备好（这个用例中是读写），就挂起，否则就继续执行。（注意， co_yield 的底层就是使用的 co_await。）

使用任务惰性估计值：

C++ 
task<int> calculate_meaning_of_life() {  co_return 42;}auto meaning_of_life = calculate_meaning_of_life();// ...co_await meaning_of_life; // == 42

概念

概念（concept）用于编译期约束类型。它们有如下形式：

C++ 
template < template-parameter-list >concept concept-name = constraint-expression;

其中 constraint-expression 的计算结果为编译期常量布尔值。约束需要为语义类型建模，例如该类型是数字类型或可哈希类型。如果给定类型不满足其绑定的概念（constraint-expression 返回 false），那么就会出现编译错误。由于评估是编译期的，所以可以提供更有意义的错误信息以及运行时安全。

C++ 
// T 没有被约束限制。template <typename T>concept always_satisfied = true;// 限制 T 为整型。template <typename T>concept integral = std::is_integral_v<T>;// 限制 T 为有符号整型。template <typename T>concept signed_integral = integral<T> && std::is_signed_v<T>;// 限制 T 为整型且并非有符号整型。template <typename T>concept unsigned_integral = integral<T> && !signed_integral<T>;

有多种句法来强化概念：

C++ 
// 函数参数的形式：// T 是个受约束类型的模板参数。template <my_concept T>void f(T v);// T 是个受约束类型的模板参数。template <typename T>  requires my_concept<T>void f(T v);// T 是个受约束类型的模板参数。template <typename T>void f(T v) requires my_concept<T>;// v 是个受约束的推导参数。void f(my_concept auto v);// v 是一个受约束的无类型模板参数。template <my_concept auto v>void g();// 自动推导变量的形式：// foo 是个受约束的自动推导值。my_concept auto foo = ...;// lambda的形式：// T 是个受约束类型的模板参数。auto f = []<my_concept T>(T v) {  // ...};// T 是个受约束类型的模板参数。auto f = []<typename T> requires my_concept<T>(T v) {  // ...};// T 是个受约束类型的模板参数。auto f = []<typename T>(T v) requires my_concept<T>{  // ...};// v 是个受约束的推导参数。auto f = [](my_concept auto v) {  // ...};// v 是一个受约束的无类型模板参数。auto g = []<my_concept auto v>() {  // ...};

requires 关键字用于开始一个 requires 子句或一个 requires 表达式。

C++ 
template <typename T>  requires my_concept<T> // requires 子句。void f(T);template <typename T>concept callable = requires (T f) { f(); }; // requires 表达式。template <typename T>  requires requires (T x) { x + x; } // requires 子句和表达式在同一行。T add(T a, T b) {  return a + b;}

请注意，requires 表达式中的参数列表是可选的。每个条件都必须是下列内容之一：

  • Simple requirements - 断言给定的表达式有效。
C++ 
template <typename T>concept callable = requires (T f) { f(); };
  • Type requirements - 表示为 typename 关键字后加一个类型名，断言给定的类型名有效。
C++ 
struct foo {  int foo;};struct bar {  using value = int;  value data;};struct baz {  using value = int;  value data;};// 使用 SFINAE, 如果 T 类型与 baz 相同就走这里。template <typename T, typename = std::enable_if_t<std::is_same_v<T, baz>>>struct S {};template <typename T>using Ref = T&;template <typename T>concept C = requires {                     // 类型 T 的条件:  typename T::value; // A) 有成员名为 value。  typename S<T>;     // B) 必须能成为 S 的模板特化参数。  typename Ref<T>;   // C) 必须成为有效的别名模板替换。};template <C T>void g(T a);g(foo{}); // 错误: 不满足条件 A.g(bar{}); // 错误: 不满足条件 B.g(baz{}); // 通过。
  • Compound requirements - 大括号表达式，后面跟一个返回类型或一个约束类型。
C++ 
template <typename T>concept C = requires(T x) {  {*x} -> std::convertible_to<typename T::inner>; // 表达式 *x 的类型可转换为 T::inner  {x + 1} -> std::same_as<int>; // 表达式 x + 1 满足 std::same_as<decltype((x + 1))>  {x * 1} -> std::convertible_to<T>; // 表达式 x * 1 的类型可转换为 T};
  • Nested requirements - 使用 requires 关键字，指定附加条件（就像本地参数那样）。
C++ 
template <typename T>concept C = requires(T x) {  requires std::same_as<sizeof(x), size_t>;};

三路比较符

C++20 使用了新的操作符 <=> 来编写比较函数，其可以减少样板代码并帮助开发者更清晰地定义比较语义。定义一个三路比较符会自动生成其它比较函数（例如 ==、!=、< 等）。

介绍如下三种形式：

  • std::strong_ordering：强序区分了相同（equal）的项目（完全相同的和可互换的）。提供 less、greater、equivalent 和 equal 的比较序。比较的例子：在一个列表中找到特定值、整数值、区分大小写的字符串。
  • std::weak_ordering：弱序区分了等价（equivalent）的项目（不完全相同，但是可以为了比较的目的而交换）。提供 less、greater 和 equivalent 比较序。比较的例子：不区分大小写的字符串、排序、比较一个类的部分但非全部可见成员。
  • std::partial_ordering：部分序遵循了和弱序一样的原则，并包括无序的情况。提供 less、greater、equivalent 和 unordered 比较序。比较的例子：浮点数值（例如 NaN）。

默认的三路比较符会对所有成员逐个比较：

C++ 
struct foo {  int a;  bool b;  char c;  // 首先比较 a，然后 b，然后 c ...  auto operator<=>(const foo&) const = default;};foo f1{0, false, 'a'}, f2{0, true, 'b'};f1 < f2; // == truef1 == f2; // == falsef1 >= f2; // == false

你也可以定义你自己的比较：

C++ 
struct foo {  int x;  bool b;  char c;  std::strong_ordering operator<=>(const foo& other) const {      return x <=> other.x;  }};foo f1{0, false, 'a'}, f2{0, true, 'b'};f1 < f2; // == falsef1 == f2; // == truef1 >= f2; // == true

指定初始化

C风格的指定初始化句法。没有在此列表里显式初始化的成员都会默认初始化。

C++ 
struct A {  int x;  int y;  int z = 123;};A a {.x = 1, .z = 2}; // a.x == 1, a.y == 0, a.z == 2

lambda表达式模板语法

在lambda表达式中使用熟悉的模板语法。

C++ 
auto f = []<typename T>(std::vector<T> v) {  // ...};

范围循环的初始化器

此功能简化了常见的代码模式，让代码更紧凑，并对常见的生命周期问题提供了一个优雅的解决方案。

C++ 
for (auto v = std::vector{1, 2, 3}; auto& e : v) {  std::cout << e;}// prints "123"

[[likely]] 与 [[unlikely]] attributes

向优化器提示被标记的语句有高概率执行。

C++ 
switch (n) {case 1:  // ...  break;[[likely]] case 2:  // n == 2 可以认为比 n 的其它值更容易出现  // ...  break;}

如果 if 右边出现了 likely/unlikely 的 attribute，表示分支很可能/不太可能被执行。

C++ 
int random = get_random_number_between_x_and_y(0, 3);if (random > 0) [[likely]] {  // if 语句主体  // ...}

也可以用于迭代语句。

C++ 
while (unlikely_truthy_condition) [[unlikely]] {  // while 语句主体  // ...}

隐式捕获this已过时

在 lambda 表达式中使用 [=] 隐式捕获 this 指针已经过时，更推荐的做法是显式使用 [=, this] 或 [=, *this]。

C++ 
struct int_value {  int n = 0;  auto getter_fn() {    // 不好:    // return [=]() { return n; };    // 好:    return [=, *this]() { return n; };  }};

非类型模板使用类类型

类现在可以用在非参数模板里了。模板参数中传入的对象具有型别 const T，其中 T 是这个对象的类型，并具有静态存储持续期。

C++ 
struct foo {  foo() = default;  constexpr foo(int) {}};template <foo f = {}>auto get_foo() {  return f;}get_foo(); // 使用隐式构造函数get_foo<foo{123}>();

constexpr虚函数

虚函数现在能添加 constexpr 并在编译期评估。constexpr 的虚函数可以重写非 constexpr 虚函数，反之亦然。

C++ 
struct X1 {  virtual int f() const = 0;};struct X2: public X1 {  constexpr virtual int f() const { return 2; }};struct X3: public X2 {  virtual int f() const { return 3; }};struct X4: public X3 {  constexpr virtual int f() const { return 4; }};constexpr X4 x4;x4.f(); // == 4

explicit(bool)

可以在编译器指定构造函数是否为显式。 explicit(true) 和直接指定 explicit 效果一样。

C++ 
struct foo {  // 指定非整型 (strings, floats, etc.) 需要显式构造。  template <typename T>  explicit(!std::is_integral_v<T>) foo(T) {}};foo a = 123; // 正确foo b = "123"; // 错误: 显式构造不能隐式转换。foo c {"123"}; // 正确

立即函数

类似于 constexpr 函数，但是函数由 consteval 指定，并产生一个常量。这被称为立即函数 immediate functions。

C++ 
consteval int sqr(int n) {  return n * n;}constexpr int r = sqr(100); // 正确int x = 100;int r2 = sqr(x); // 错误: 变量 x 不能使用于常量表达式。                 // 如果 sqr 是 constexpr 函数这个就能编过了。

using enum

指定枚举的命名空间来提升可读性。

以前：

C++ 
enum class rgba_color_channel { red, green, blue, alpha };std::string_view to_string(rgba_color_channel channel) {  switch (channel) {    case rgba_color_channel::red:   return "red";    case rgba_color_channel::green: return "green";    case rgba_color_channel::blue:  return "blue";    case rgba_color_channel::alpha: return "alpha";  }}

现在：

C++ 
enum class rgba_color_channel { red, green, blue, alpha };std::string_view to_string(rgba_color_channel my_channel) {  switch (my_channel) {    using enum rgba_color_channel;    case red:   return "red";    case green: return "green";    case blue:  return "blue";    case alpha: return "alpha";  }}

lambda表达式捕获参数包

按值捕获参数包：

C++ 
template <typename... Args>auto f(Args&&... args){    // 按值捕获：    return [...args = std::forward<Args>(args)] {        // ...    };}

按引用捕获参数包：

C++ 
template <typename... Args>auto f(Args&&... args){    // 按引用捕获参数包：    return [&...args = std::forward<Args>(args)] {        // ...    };}

char8_t

提供表示 UTF-8 字符串的标准类型。

C++ 
char8_t utf8_str[] = u8"\u0123";

constinit

constinit 指定的变量必须在编译期初始化。

C++ 
const char* g() { return "dynamic initialization"; }constexpr const char* f(bool p) { return p ? "constant initializer" : g(); }constinit const char* c = f(true); // 正确constinit const char* d = f(false); // 错误: g 不是 constexpr，所以 d 不能在编译期求值。

__VA_OPT__

帮助支持可变宏，如果其不为空那么就对给定的参数求值。

C++ 
#define F(...) f(0 __VA_OPT__(,) __VA_ARGS__)F(a, b, c) // 替换为 f(0, a, b, c)F()        // 替换为 f(0)

C++20库特性

概念库

标准库也提供概念库，来创建更多复杂概念。其中包括：

Core language concepts：

  • same_as - 指定两个类型相同。
  • derived_from - 指定一个类型继承自另一个类型。
  • convertible_to - 指定一个类型可以隐式转换为另一个类型。
  • common_with - 指定两个类型共享同一个类型。
  • integral - 指定整型。
  • default_constructible - 指定这个类型的对象可以被默认构造。

Comparison concepts：

  • boolean - 指定这个类型可以使用布尔上下文。
  • equality_comparable - 指定 operator== 可以表示相等关系。

Object concepts：

  • movable - 指定对象可以被移动和交换。
  • copyable - 指定对象可以被拷贝、移动和交换。
  • semiregular - 指定对象可以被拷贝、移动、交换和默认构造。
  • regular - 指定对象既 semiregular 又 equality_comparable。

Callable concepts：

  • invocable - 指定这个可调用的类型可以被指定参数列表调用。
  • predicate - 指定调用类型有布尔返回值。

另见：概念。

格式化库

结合了 printf 的简单性和 iostream 的安全性。使用大括号占位符，并支持与 printf 样式指定符类似的自定义格式。

C++ 
std::format("{1} {0}", "world", "hello"); // == "hello world"int x = 123;std::string str = std::format("x: {}", x); // str == "x: 123"// 格式化到一个输出迭代器：for (auto x : {1, 2, 3}) {  std::format_to(std::ostream_iterator<char>{std::cout, "\n"}, "{}", x);}

自定义格式化类型：

C++ 
struct fraction {  int numerator;  int denominator;};template <>struct std::formatter<fraction>{    constexpr auto parse(std::format_parse_context& ctx) {      return ctx.begin();    }    auto format(const fraction& f, std::format_context& ctx) const {      return std::format_to(ctx.out(), "{0:d}/{1:d}", f.numerator, f.denominator);    }};fraction f{1, 2};std::format("{}", f); // == "1/2"

同步缓冲输出流

缓冲输出流以确保同步（即输出没有交错）。

C++ 
std::osyncstream{std::cout} << "The value of x is:" << x << std::endl;

std::span

span 是一个对容器查看的视图（非拥有），并提供对连续元素组的边界检查。由于视图并不持有元素，所以构造与拷贝的成本很低。思考这些视图的简单方式就是把它们看作是对数据的引用。与维护指针/迭代器长度不同的是，span 把这些都封装到一个对象里。

span 可以是动态大小的，也可以是固定大小的。固定大小的 span 可以受益于边界检查。

span 不支持 const，所以需要构造只读的 span 时请使用 std::span<const T>。

示例：使用动态大小的 span 从不同容器中打印整数。

C++ 
void print_ints(std::span<const int> ints) {    for (const auto n : ints) {        std::cout << n << std::endl;    }}print_ints(std::vector{ 1, 2, 3 });print_ints(std::array<int, 5>{ 1, 2, 3, 4, 5 });int a[10] = { 0 };print_ints(a);// ...

示例：静态大小的 span 塞进去大小不一致的容器就会编译失败。

C++ 
void print_three_ints(std::span<const int, 3> ints) {    for (const auto n : ints) {        std::cout << n << std::endl;    }}print_three_ints(std::vector{ 1, 2, 3 }); // 错误print_three_ints(std::array<int, 5>{ 1, 2, 3, 4, 5 }); // 错误int a[10] = { 0 };print_three_ints(a); // 错误std::array<int, 3> b = { 1, 2, 3 };print_three_ints(b); // 正确// 如果需要可以手动构造 span。std::vector c{ 1, 2, 3 };print_three_ints(std::span<const int, 3>{ c.data(), 3 }); // 正确: 设置指针和长度范围。print_three_ints(std::span<const int, 3>{ c.cbegin(), c.cend() }); // 正确: 使用迭代器。

位操作

C++20 提供了新的 <bit> 头文件并提供了一些位操作，包括 popcount（算二进制有几个1）。

C++ 
std::popcount(0u); // 0std::popcount(1u); // 1std::popcount(0b1111'0000u); // 4

数学常数

数学常数，包括π、e等，在 <numbers> 头文件中。

C++ 
std::numbers::pi; // 3.14159...std::numbers::e; // 2.71828...

std::is_constant_evaluated

谓词函数，如果编译期上下文调用就返回 true。

C++ 
constexpr bool is_compile_time() {    return std::is_constant_evaluated();}constexpr bool a = is_compile_time(); // truebool b = is_compile_time(); // false

std::make_shared 支持数组

C++ 
auto p = std::make_shared<int[]>(5); // 指向 int[5] 的指针// 或auto p = std::make_shared<int[5]>(); // 指向 int[5] 的指针

字符串的 starts_with 和 ends_with

string（和string_view）现在有 starts_with 和 ends_with 两个成员函数，以检查是否以给定字符串开始或结束。

C++ 
std::string str = "foobar";str.starts_with("foo"); // truestr.ends_with("baz"); // false

检测关联容器是否包含元素

现在关联容器，例如 set 或者 map，具有 contains 成员函数，以代替“寻找并且与迭代器末尾比较”的编程方式。

C++ 
std::map<int, char> map {{1, 'a'}, {2, 'b'}};map.contains(2); // truemap.contains(123); // falsestd::set<int> set {1, 2, 3};set.contains(2); // true

std::bit_cast

一个更安全的方式，把一个对象从一个类型转换到另一个类型。

C++ 
float f = 123.0;int i = std::bit_cast<int>(f);

std::midpoint

更安全地计算两个整数的中点（无溢出）。

C++ 
std::midpoint(1, 3); // == 2

std::to_array

把数组或者类似数组的对象转换为 std::array。

C++ 
std::to_array("foo"); // 返回 std::array<char, 4>std::to_array<int>({1, 2, 3}); // 返回 std::array<int, 3>int a[] = {1, 2, 3};std::to_array(a); // 返回 std::array<int, 3>

std::bind_front

绑定前 N 个参数（N 是指定函数到 std::bind_front 后的参数个数）到给定的自由函数、lambda 或成员函数。

C++ 
const auto f = [](int a, int b, int c) { return a + b + c; };const auto g = std::bind_front(f, 1, 1);g(1); // == 3

统一容器擦除

对于各种容器，例如 string、list、vector、map 等，提供 std::erase 和/或 std::erase_if。

擦除值使用 std::erase，或者在使用 std::erase_if 的时候指定谓词。这两个函数都会返回擦除元素的数量。

C++ 
std::vector v{0, 1, 0, 2, 0, 3};std::erase(v, 0); // v == {1, 2, 3}std::erase_if(v, [](int n) { return n == 0; }); // v == {1, 2, 3}

三路比较助手

给定比较函数的助手函数。

C++ 
std::is_eq(0 <=> 0); // == truestd::is_lteq(0 <=> 1); // == truestd::is_gt(0 <=> 1); // == false

另见：三路比较符

std::lexicographical_compare_three_way

使用三路比较法对两个范围进行顺序比较，得出适用于比较的最强结果的种类类型。

C++ 
std::vector a{0, 0, 0}, b{0, 0, 0}, c{1, 1, 1};auto cmp_ab = std::lexicographical_compare_three_way(    a.begin(), a.end(), b.begin(), b.end());std::is_eq(cmp_ab); // == trueauto cmp_ac = std::lexicographical_compare_three_way(    a.begin(), a.end(), c.begin(), c.end());std::is_lt(cmp_ac); // == true
